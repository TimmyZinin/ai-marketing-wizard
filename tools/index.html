How to pay

Two rails, same tools

x402 · for AI agents

Call POST https://api.timzinin.com/api/<tool> with no auth. You get back HTTP 402 with the exact price in USDC on Base. An x402-aware client signs the payment and retries — you only pay if the run succeeds. Full manifest at https://api.timzinin.com/.well-known/x402.

Apify Store · for humans

No wallet? Every tool is also a published Apify Actor — run it in the browser or from Apify's own API, pay by card through Apify's billing. Same input, same output, different rail.
