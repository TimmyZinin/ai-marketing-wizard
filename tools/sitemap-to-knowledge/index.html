Sitemap to Knowledge — RAG Dataset Builder, No LLM

Point it at a domain and get back an embedding-ready dataset of clean text chunks, pulled straight from that site's sitemap — no crawler to configure, no browser, no LLM call. Built for anyone assembling a RAG knowledge base out of a website's own docs instead of paying for a full scraping-platform seat to pull a few hundred pages.

$0.02 / call x402 · USDC on Base also on Apify
What it does

Straight answers, no browser required

  • Chunks, not pages. Every page found is stripped of scripts/styles/nav/header/footer, decoded, and split into ~1000-character, word-boundary-aware chunks — one row per chunk, ready to embed.
  • Finds the sitemap itself. Discovers /sitemap.xml, falls back to /sitemap_index.xml, and follows one level of sitemap-index (child sitemaps) to collect page URLs. No sitemap at all? Falls back to the homepage instead of returning nothing.
  • Cost stays predictable. Capped at 25 pages and ~200 chunks per site, so a run can't run away into an unbounded bill.
  • Internal addresses are refused, including through a redirect — a safety guarantee that holds even if a sitemap links somewhere it shouldn't.
  • Built for lists. Concurrency up to 20 sites at once, so a portfolio of docs sites is a single run.
  • Runs on Apify: schedule it, monitor it, call it from the API or the MCP server, export to JSON, CSV or Excel, or push results straight into your own pipeline.
Call it

Two ways to pay

Agents with a wallet pay per call in USDC over HTTP 402 — no API key, no signup. Humans (or agents without a wallet yet) can run the same tool on the Apify Store and pay by card.

1 · Call without payment → get the price

Every call starts unauthenticated. No payment header means the hub answers HTTP 402 with exact PaymentRequirements — no guessing, no docs to read first.

curl -s -X POST https://api.timzinin.com/api/sitemap-to-knowledge \
  -H "Content-Type: application/json" \
  -d '{"items": ["docs.apify.com", "example.com"]}'

2 · Sign the payment, retry once → get data

An x402-aware HTTP client (e.g. x402-fetch, x402-axios) signs a USDC transfer on Base for the exact amount and resends the request with an X-PAYMENT header. The hub verifies the signature, runs the tool, and only settles the payment if the run succeeds — a failed run costs you nothing.

curl -s -X POST https://api.timzinin.com/api/sitemap-to-knowledge \
  -H "Content-Type: application/json" \
  -H "X-PAYMENT: <base64 payment payload from your x402 client>" \
  -d '{"items": ["docs.apify.com", "example.com"]}'
